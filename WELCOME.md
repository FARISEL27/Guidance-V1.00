# 🎉 Bienvenue sur le projet RORK !

Salut ! Merci de rejoindre ce projet passionnant. Voici comment démarrer :

## 🚀 Étapes pour commencer

### 1. Cloner le projet
```bash
git clone https://github.com/Fariselb27/RORK.git
cd RORK
```

### 2. Installer les dépendances
```bash
npm install
```

### 3. Tester l'animation de respiration
Le cœur du projet se trouve dans **`app/breath-out.tsx`**

C'est là que tu trouveras l'animation de respiration interactive ! Lance le projet avec :
```bash
npm start
```
